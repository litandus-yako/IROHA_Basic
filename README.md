# IROHA_Basic (イロハ ベーシック)
A quick hyperspectral data analyzer based on rule-based approaches
本ソフトウェア『IROHA_Basic』は、研究者や技術者が手元のハイパースペクトル画像データを直感的に読み込み・可視化・セグメンテーション（分類）するためのオープンソース/フリーのデスクトップアプリケーションです。
見えない光の波長（スペクトル）情報を解き明かす「イロハ（基本）」となるツールとして開発されています。

---

## 主な機能

* ENVIフォーマットの高速ロード
  * ENVI形式に対応し、ヘッダーファイル (`.hdr`) を用いた読み込みに対応。
* ROI（関心領域）の選択とスペクトル可視化
  * 疑似RGB画像を見ながら、マウス操作による直観的な操作で、選択領域の平均スペクトルを抽出・表示。
* 5種類のアルゴリズムを切り替えて柔軟な分析を簡単に実施
  * 選択したROIのスペクトル特徴量を基に、ハイパースペクトルデータから簡単にセグメンテーションを実施。

---

## 動作環境

* 対応OS: Windows 10 / 11 (64-bit)
* メモリ: 8 GB 以上推奨 (扱うハイパースペクトルデータのサイズに依存します)
* ディスプレイ解像度: 1280×720 以上（ディスプレイ解像度に合わせて文字サイズを動的に変えるため、ズーム倍率が高いと視認性が悪くなることがあります）

## インストール手順

1. リポジトリ（https://github.com/litandus-yako/IROHA_Basic）より最新の `IROHA_Basic_Setup.msi` をダウンロードします。
2. ダウンロードした `.msi` ファイルをダブルクリックしてインストーラーを起動します。Microsoft Defenderの警告が表示された場合は、詳細情報→実行、などで回避してください（自己責任）。
3. 画面の指示に従ってインストールを完了させてください。
4. インストール完了後、デスクトップに作成される「IROHA_Basic」アイコン、もしくは解答先フォルダ内のexeファイルから起動できます。

## 基本的な使い方

1. データを開く
   * ウインドウ左上の[Load HS Data (.hdr)] ボタンより、対象の `.hdr` ファイルを指定します。ロード完了後、疑似RGB画像がウインドウ右側に表示されます。
2. 画像の調整
   * 疑似RGB画像の視認性調整が必要な場合、「明るさ倍率」スライダーを操作します。
3. ROI（解析領域）の指定
   * 画像上でドラッグして矩形領域を選択し、領域ごとのスペクトル特性を確認します。選択領域の平均スペクトルが、ウインドウ左下のグラフウインドウに表示されます。
4. 分類の実行
   * 分類に用いるアルゴリズムをプルダウンより選択します。アルゴリズムの簡易的な説明は[詳細]ボタンより確認できます。[実行]ボタンを押すことで、設定したROIを学習データとした分類が実行されます。
5. データ保存
   * 分類結果は別ウインドウで表示されるので、結果を確認し、[画面保存]ボタンから画像として保存します。

## 高度な機能が必要な方へ（IROHA_Proのご案内）

`IROHA_Basic` は1枚の画像に対するインタラクティブな探査・可視化に特化しています。
研究・業務において一括処理や定量的解析が方は、今後リリース予定の `IROHA_Pro`（有償版）をご検討ください。

【IROHA_Pro で開発予定の主な機能（開発内容は予告なく変わる可能性があります）】
* 分類モデルの保存・読み込みおよび特徴量CSV出力
* 複数ハイパースペクトルデータの一括バッチ処理
* PLSR（部分最小二乗回帰）による定量評価
* ベクター形式の画像エクスポート
